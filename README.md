# Nameless Assembly
A work in progress game

## Running the game
  1. **Prerequisite**: Using windows 10 or newer (Linux/macOS release unavailable)
  2. Download release for from the [release page](https://github.com/POROSIVE/Nameless-Assembly/releases/)
  3. extract the files
  4. Run the binary `Nameless Assembly.exe`
  * note: do not extract the release files into program folder in windows or any other folder that required admin level access as it can cause to break the program even given administrator access

## controls
- for movement using `w,a,s,d` for moving around
- `space` for jump
- `ctrl` for crouching
- `shift` for running
- `tab` for open/close inventory
- `e` for interacting with unit
- `esc` for in game settings
